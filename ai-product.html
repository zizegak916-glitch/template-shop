Developer Experience

Ship in Minutes, Not Months

A clean, intuitive API that integrates with any stack in under 10 lines of code.

api.neuralai.dev/v2/inference
// Initialize the NeuralAI client
import { NeuralAI } from '@neuralai/sdk';

const ai = new NeuralAI({ apiKey: 'nai_sk_...' });

// Run inference with streaming response
const stream = await ai.inference({
  model: 'neural-7b-turbo',
  messages: [{ role: 'user', content: 'Analyze sentiment' }],
  temperature: 0.7,
  stream: true
});

for await (const chunk of stream) {
  process.stdout.write(chunk.text);
}

FAQ

Frequently Asked Questions

How does the free tier work?
The free tier includes 10,000 API calls per month, access to 2 foundational models, and community support. No credit card required to get started.
Can I fine-tune models on my own data?
Yes! Enterprise plans include custom fine-tuning with your proprietary datasets. We support LoRA, QLoRA, and full fine-tuning with dedicated GPU clusters.
Is my data secure?
Absolutely. We're SOC2 Type II certified, use AES-256 encryption at rest, TLS 1.3 in transit, and offer self-hosted deployment options for maximum data sovereignty.
What SDKs do you support?
Official SDKs for Python, TypeScript/JavaScript, Go, Rust, and Java. Community-maintained libraries are available for Ruby, PHP, and Swift.
