# NexusAI - SaaS Landing Page Template

暗黑科技风落地页模板，适合 AI/SaaS/科技产品。

## 功能
- ✅ 纯 HTML/CSS，无依赖
- ✅ 完全响应式（手机/平板/桌面）
- ✅ CSS 变量一键换色
- ✅ 10 个完整区块（导航/特性/定价/FAQ/页脚）
- ✅ 交互动画（hover/scroll/FAQ 折叠）
- ✅ 移动端汉堡菜单

## 自定义
修改 `:root` 中的 CSS 变量即可换色：
```css
:root {
  --primary: #6C5CE7;    /* 主色 */
  --accent: #00cec9;     /* 强调色 */
  --bg: #0a0a1a;         /* 背景色 */
}
```
