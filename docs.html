快速开始

下载模板

  • 游客模式 — 所有模板均可在线预览，无需登录即可浏览全部 28 套模板的设计效果。
  • 密钥用户 — 输入密钥登录后，可下载任意模板的完整源码（.html 单文件）。

打开方式

1
直接浏览器打开

双击 .html 文件，或将其拖入浏览器窗口，即可查看完整效果。

2
VS Code 编辑

将文件拖入 VS Code，使用 Live Server 插件实时预览修改效果。

所有模板均为纯 HTML/CSS/JS 单文件，零依赖，无需安装任何框架或构建工具。下载后即可直接使用。

自定义修改

换颜色

每个模板都使用 CSS 变量控制颜色，搜索以下变量名即可快速修改：

CSS 
:root {
  --primary: #6C5CE7;    /* 主色 — 按钮、链接、强调色 */
  --accent: #00cec9;     /* 辅助色 — 渐变、装饰 */
  --bg: #07070e;         /* 页面背景 */
  --text: #e8e8f4;       /* 正文文字颜色 */
  --card-bg: #0e0e1a;    /* 卡片背景 */
}
使用 VS Code 的全局搜索（Ctrl+Shift+F）搜索 --primary 或 --bg，即可找到所有可自定义的颜色变量。

换文字

  • 直接在 HTML 文件中找到对应中文内容，替换为你的文案即可。
  • 大多数模板的标题、描述、按钮文字都集中在 <section> 标签内。

换图片

  • 替换 <img> 标签的 src 属性为你的图片路径。
  • 修改 CSS 中的 background-image: url(...) 更换背景图。
  • 建议使用 Unsplash 等免费图库获取高质量图片。

换字体

  • 修改 <link> 标签中的 Google Fonts 链接，替换为你喜欢的字体。
  • 同时修改 CSS 中的 font-family 属性。
HTML 
<!-- 替换 Inter 为其他字体 -->
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&display=swap" rel="stylesheet">

部署上线

所有模板均为静态 HTML 文件，可部署到任意静态托管平台。

GitHub Pages

1
推送代码到 GitHub 仓库

将 .html 文件推送到你的 GitHub 仓库。

2
开启 Pages

进入仓库 Settings → Pages → Source 选择 main 分支 → 保存。

3
访问你的网站

等待 1-2 分钟，访问 https://yourname.github.io/repo/ 即可。

Cloudflare Pages

  • 登录 Cloudflare Pages，连接 GitHub 仓库。
  • 无需配置构建命令，自动部署，访问速度全球加速。

Vercel / Netlify

  • 直接将 .html 文件拖拽上传到平台，即刻上线。
  • 支持自定义域名和自动 HTTPS。

任意静态服务器

  • 上传文件到 Nginx、Apache、Caddy 等静态服务器即可。
  • 无需后端，无需数据库，纯静态托管。
推荐使用 Cloudflare Pages — 免费额度充足，全球 CDN 加速，自带 HTTPS，部署最简单。

响应式适配

  • 所有模板已全面适配 手机 / 平板 / 桌面 三种屏幕尺寸。
  • 默认断点：@media (max-width: 768px)（平板）、@media (max-width: 480px)（手机）。
  • 如需自定义断点，在 CSS 中搜索 @media 查询并修改即可。

测试建议

  • 使用 Chrome DevTools 的 设备模式（F12 → 点击手机图标）快速切换不同设备预览。
  • 推荐测试 iPhone SE、iPhone 14、iPad、桌面 1440px 四种尺寸。
  • 特别注意导航栏、按钮、表格在小屏幕上的显示效果。
CSS 
/* 典型响应式断点结构 */
@media (max-width: 768px) {
  .hero h1 { font-size: 32px; }
  .grid { grid-template-columns: 1fr; }
}
@media (max-width: 480px) {
  .hero h1 { font-size: 28px; }
  .nav-links { display: none; }
}

密钥系统

游客模式

  • 无需登录即可预览所有模板的设计效果。
  • 游客模式下不可下载源码文件。
  • 可在首页自由浏览、搜索、筛选模板。

密钥登录

  • 密钥格式：TMPL-XXXX-XXXX-XXXX（X 为大写字母或数字）。
  • 输入密钥后系统自动校验，通过后即可下载全部模板源码。
  • 密钥支持自动补全格式，输入时无需手动输入连字符。

设备绑定

  • 一个密钥绑定一台设备，通过设备指纹识别。
  • 切换设备（换浏览器、换电脑）后需重新登录。
  • 系统会自动检测设备变更并提示重新验证。

获取密钥

  • 通过 GitHub Issues 联系获取密钥。
  • 提交 Issue 时请说明使用场景，我们会尽快回复。
请妥善保管你的密钥。设备变更、浏览器清除缓存后均需重新输入密钥登录。

FAQ

能否商用？
可以。所有模板无版权限制，可用于个人或商业项目，包括 SaaS 产品、落地页、营销页面等。
能否二次销售？
不建议直接转售模板本身。你可以基于模板创建定制化项目交付给客户，但不应原样转卖模板文件。
遇到 bug 怎么办？
请到 GitHub Issues 提交 bug 反馈，描述问题复现步骤，我们会尽快修复。
需要定制开发？
联系我们，支持企业定制开发。可以根据你的品牌需求修改颜色、内容、布局，或从零构建全新落地页。
支持哪些浏览器？
支持所有现代浏览器：Chrome、Firefox、Safari、Edge 的最新版本。不支持 IE。
模板会持续更新吗？
会。我们持续迭代模板库，添加新模板和改进现有模板，更新记录详见更新日志。
