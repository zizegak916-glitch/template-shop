## ✨ Features 特性

| 特性 | 说明 |
|------|------|
| 🌓 **暗色/亮色主题切换** | 一键切换浏览界面的暗色与亮色模式，模板预览区保持原始风格 |
| 🔍 **搜索与筛选** | 支持按模板名称、风格关键词实时搜索，支持按分类快速筛选 |
| 🖼️ **懒加载 iframe 预览** | 所有模板预览采用 `loading="lazy"` 的 iframe 方式加载，首屏性能优异 |
| 📱 **全面响应式设计** | 浏览界面及所有模板均完美适配桌面端、平板端和移动端 |
| 📄 **单文件模板** | 每个模板均为独立的单 HTML 文件（500+ 行），零外部依赖，易于移植 |
| ⚡ **零框架** | 不使用 React / Vue / Angular 等框架，纯原生 HTML + CSS + JavaScript |
| 🌐 **CDN 加速** | 托管于 GitHub Pages，通过 Cloudflare CDN 全球加速 |

## 🚀 Quick Start 快速开始

### 方式一：在线浏览（推荐）

直接访问线上地址，即可浏览全部模板：

```
https://your-username.github.io/template-shop/
```

### 方式二：本地运行

```bash
# 1. 克隆仓库
git clone https://github.com/your-username/template-shop.git

# 2. 进入项目目录
cd template-shop

# 3. 启动本地服务器（任选一种方式）

# 方式 A：使用 Python
python -m http.server 8080

# 方式 B：使用 Node.js
npx serve .

# 方式 C：使用 PHP
php -S localhost:8080

# 4. 打开浏览器访问
open http://localhost:8080
```

### 方式三：直接使用单个模板

每个模板都是独立的 HTML 文件，可直接复制到任何项目中使用：

```bash
# 直接在浏览器中打开任意模板文件
open templates/dark/cyberpunk.html
open templates/ink/ink-wash.html
open templates/new/deep-sea-glow.html
```

## ➕ How to Add New Templates 如何添加新模板

欢迎为本项目贡献新的落地页模板！请按照以下步骤操作：

### 第一步：创建模板文件

每个模板必须是一个**独立的单 HTML 文件**，满足以下要求：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>模板名称 — Template Shop</title>
    <style>
        /* 所有样式内联在此，不引用外部 CSS 文件 */
        /* 建议使用 CSS Variables 定义主题色，方便定制 */
        :root {
            --primary: #your-color;
            --secondary: #your-color;
            --bg: #your-color;
            --text: #your-color;
        }
        /* ... 500+ 行样式代码 ... */
    </style>
</head>
<body>
    <!-- 
        落地页结构建议包含以下区块：
        1. 导航栏 (Navigation)
        2. 主视觉/英雄区 (Hero Section)
        3. 功能/特性展示 (Features)
        4. 社会证明/评价 (Testimonials)
        5. 定价方案 (Pricing) — 可选
        6. 行动号召 (CTA)
        7. 页脚 (Footer)
    -->

    <script>
        /* 所有脚本内联在此，不引用外部 JS 文件 */
    </script>
</body>
</html>
```

### 第二步：模板规范

| 规范项 | 要求 |
|--------|------|
| **文件格式** | 单一 `.html` 文件，所有 CSS 和 JS 内联 |
| **最低行数** | 500 行以上（确保模板内容丰富） |
| **响应式** | 必须适配 320px ~ 2560px 宽度 |
| **浏览器兼容** | 支持 Chrome、Firefox、Safari、Edge 最新两个版本 |
| **外部依赖** | ❌ 不允许引用任何外部 CSS/JS 框架或库 |
| **命名规范** | 文件名使用小写英文 + 连字符（kebab-case），如 `cherry-rain.html` |
| **编码格式** | UTF-8 |
